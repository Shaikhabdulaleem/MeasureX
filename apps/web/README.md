# apps/web

Next.js (React, TypeScript) web dashboard for Team Leader and Admin.
**Skeleton only** in Milestone 0 — the dashboard pages land in M4.

Stack (PRD §14): Next.js + Tailwind, i18n with RTL (English + Arabic).
Talks only to the API ([`../../docs/openapi.yaml`](../../docs/openapi.yaml));
nothing on the web touches the database directly.
